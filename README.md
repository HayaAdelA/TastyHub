# 🍽️ TastyHub - Restaurant Management System

**TastyHub** is a Java-based desktop application built with **Java Swing** and integrated with a **MySQL database**. It is designed to streamline the operations of a restaurant by managing menus, staff, orders, and customer feedback in a user-friendly interface.

---

## 📌 Features

### 👤 User Roles
- **Customer**: Register, browse the menu, place orders, and submit feedback.
- **Employee**: Manage orders and assist customers.
- **Admin**: Full access to manage menu items, staff members, view reports, and handle system settings.

### 🍕 Menu Management
- Add, update, or remove menu items.
- View all available dishes with images and prices.

### 🧑‍🍳 Staff Management
- Add and edit employee details (name, salary, contact info).
- Assign roles and manage user access levels.

### 📦 Order Management
- Place new orders and search existing ones by ID.
- Update order status or cancel orders.
- Export order data to **PDF** or **CSV**.

### 📈 Reports
- View daily/weekly/monthly sales.
- Visualize performance metrics (e.g., most popular dishes, total revenue).

### 📬 Feedback System
- Customers can submit reviews and suggestions.
- Admin can monitor feedback for quality control.

---

## 🛠️ Technologies Used

- **Java (Swing GUI)** – for building the desktop interface
- **MySQL** – for persistent data storage
- **JDBC** – to connect Java with the database
- **PDF/CSV Export Libraries** – for generating reports
